# Data Explorer

The Data Explorer is a web app for browsing the BoSS.

```{button-link} https://boss.flatironinstitute.org/viewer/
:color: primary
:shadow:

Open the Data Explorer
```

Filter configurations by their properties, such as source database, number of
field periods, aspect ratio, and loss fraction, then open one to look at its
boundary surface in 3-D, its profiles and $\lvert B \rvert$, and its
alpha-particle losses.

The Data Explorer is for looking at individual records. To work with the data
in bulk, see [Download Data](download.md).
